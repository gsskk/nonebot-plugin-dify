# 手动画像生成脚本使用指南

`scripts/manual_profiler.py` 是一个用于手动触发群组或私聊画像生成的辅助脚本。这对于重新生成特定日期的画像或在错过了定时任务后补跑数据非常有用。

## 功能说明

该脚本允许你指定以下参数来运行画像生成任务：
- **类型**：群组 (`group`) 或 私聊 (`private`)
- **平台适配器**：例如 `onebotv11`
- **目标 ID**：群号或用户 ID
- **日期**：目标数据的结束日期 (默认分析该日期前 24 小时的数据)
- **时间**：(可选) 具体的结束时间点

## 使用方法

在使用脚本前，请确保你已经安装了项目的依赖环境（通常在 `.venv` 中）。

### 命令格式

```bash
/path/to/python scripts/manual_profiler.py --type <类型> --adapter <适配器名> --id <ID> --date <日期> [--time <时间>]
```

### 参数详解

| 参数 | 必选 | 描述 | 示例 |
| :--- | :--- | :--- | :--- |
| `--type` | 是 | 任务类型，可选值: `group`, `private` | `--type group` |
| `--adapter` | 是 | 适配器名称，需与此时 NoneBot 中使用的名称一致 | `--adapter "onebotv11"` |
| `--id` | 是 | 目标群组 ID 或 用户 ID | `--id 123456789` |
| `--date` | 是 | 目标日期，格式 `YYYY-MM-DD`。<br>脚本将分析以此日期（及可选时间）为**结束点**的过去 24 小时数据。 | `--date 2023-10-27` |
| `--time` | 否 | 具体结束时间，格式 `HH:MM:SS`。<br>默认为 `03:00:00` (与定时任务默认时间一致)。 | `--time 14:00:00` |

### 使用示例

#### 1. 重新生成某群组在 10 月 27 日的画像
假设群号为 `123456`，适配器为 `onebotv11`，我们希望重新跑一下 10 月 27 日凌晨 3 点的定时任务逻辑（即分析 10 月 26 日 03:00 到 10 月 27 日 03:00 的数据）：

```bash
./.venv/bin/python scripts/manual_profiler.py --type group --adapter "onebotv11" --id 123456 --date 2023-10-27
```

#### 2. 手动触发特定用户的私聊画像分析
假设用户 ID 为 `987654321`，适配器为 `onebotv11`，我们想分析截止到今天中午 12 点的过去 24 小时数据：

```bash
./.venv/bin/python scripts/manual_profiler.py --type private --adapter "onebotv11" --id 987654321 --date 2026-02-06 --time 12:00:00
```

## 注意事项

1. **适配器名称**：请务必确认 `--adapter` 参数与数据库/日志中存储的名称完全一致（例如 `onebotv11` 而不是 `OneBot V11`），否则可能无法找到对应的聊天记录。
2. **数据依赖**：画像生成依赖于本地存储的聊天记录。如果你指定的时间段内没有聊天记录（或者记录已被清理），脚本将不会生成新的画像或会提示消息不足。
3. **API 消耗**：手动运行脚本同样会调用 Dify API，请注意 Token 消耗。
